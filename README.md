Water Leakage Reporting and Tracking System

About

A web-based application that allows users to report water leakage problems and track their repair status.

Features

- Submit water leakage complaints.
- Enter the location and description of a leak.
- Track complaint and repair status.
- Help reduce water wastage.

Technologies Used

- HTML, CSS, JavaScript
- Node.js and Express.js
- MongoDB

How to Run

1. Install Node.js and MongoDB.
2. Download or clone this repository.
3. Run "npm install".
4. Start MongoDB.
5. Run "node server.js".
6. Open the local URL displayed by your server in the browser.

Project Goal

To make water leakage reporting easier and support faster repairs.
